# 秒 · SECONDS

一个"时间即货币"的 2D 白模动作原型。

**你没有血量。** 被打中不会死，只会往计时器上加秒数。买强化要花秒、开捷径要花秒、修复伤势也要花秒。而 Boss 的强度，等于你累计的总时间。

> 每一个决定，都只是同一个问题：这值几秒？

## 试玩

浏览器直接打开即可（单文件、零依赖、无需安装）。

## 操作

| 键位 | 动作 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| 鼠标移动 | 瞄准 |
| 鼠标左键 | 挥砍（也能打掉飞来的红弹） |
| `空格` / 鼠标右键 | **朝光标**冲刺，0.17 秒完全无敌 |
| `1` `2` `3` `4` | 选卡 |

角色身上的蓝环 = 冲刺冷却。

冲刺方向**只看光标,不看移动键**,而且在按下的那一帧就锁死,途中不能转向。想往哪躲就把光标甩到哪——包括往身后。

## 规则

**总时间 = 游戏时间 + 受击惩罚 + 秒数消费 − 击杀返还**

一章 7 个节点。每清空一个房间给你 2–3 张明码标价的路线卡：

- **战斗房 / 精英房** — 免费给强化（战斗消耗的游戏时间就是学费）
- **秒商店** — 用秒数买强化，永远买得起，因为代价直接记在成绩上
- **捷径门** — 花 9s 跳过一个节点，省时间但少拿一个强化
- **时间修复站** — 花 12s 抹掉已累计受击惩罚的 40%

右上角的 **BOSS 强度**随总时间上涨（总时间 ÷ 150）。变强的代价是终局变难。

打完 Boss 结算，按总时间评级，S 是 150 秒以内。

## 连击税

挨打后有 0.4 秒无敌，但**别把它当成免费的穿墙权**。

5 秒内每多挨一次，价码 ×1.3 —— 第一下 2.0s，第二下 2.6s，第三下 3.4s。5 秒不挨打则清零。

## 看价签

场上每一个会收你钱的东西都挂着实时价签，**上面的数字就是你此刻挨这一下会被扣的秒数**，已经算进强化和连击税：

- **红色** — 常态报价
- **橙色加粗** — 连击税生效中，正在加价
- **绿色「免费」** — 你正处于无敌帧，这一瞬间全场真的不要钱

飞行中的红弹也有价签，靠近时逐渐显现。Boss 会分招式报价：起手三层环时标 `+3.0s`，起手收缩圆时标 `+2.5s`，冲锋接触是 `+5.0s`。

## 怎么读敌人

红色 = 马上要收你钱。下面标的是无强化、无连击税时的底价。

- **三角形（冲锋兵，+2.0s）** — 画红色锁定射线后高速冲刺。方向在预警开始时就锁死，侧移一步即可
- **方块（射手，+1.5s）** — 红色虚线锁定后打一发红弹
- **六边形（重甲，+4.0s）** — 脚下红圈向外扩，扩满瞬间全圈伤害
- **八边形（Boss）** — 粗红线=三连冲锋 / 收缩圆=环形弹幕 / 三层同心环=三段地震波，卡空隙

## 这个原型想验证什么

**能不能不断地提高自己的操作来让游戏时间越来越短，让每次收到攻击也被算作时间惩罚。**

玩的时候留意自己有没有真的这么算过账。如果有，这个设计成立。

调平衡的旋钮都在 `index.html` 开头：`BASE`（角色数值）、`INV_TIME` / `TAX_WINDOW` / `TAX_STEP`（受击经济学）、`mkEnemy` 里的 `pen`（各敌人时间价码）、`bossScale`（Boss 缩放系数）。
