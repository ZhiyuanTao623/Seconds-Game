# 秒 · SECONDS

**[English](README.en.md)**

一个"时间即货币"的 2D 白模动作**竞速**原型。

**你没有血量。** 被打中不会死，只会往计时器上加秒数。买强化要花秒、开捷径要花秒、修复伤势也要花秒。**连站在地图和商店界面思考，时钟也在走。**

> 每一个决定，都只是同一个问题：**能不能更快？**

完整的玩法规格见 [DESIGN.md](DESIGN.md)。

## 跑起来

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 产出 dist/index.html —— 仍然是单文件，双击即玩
npm test           # 报价一致性 + seed 可复现 + 启动冒烟
```

构建产物是**一个自包含的 HTML 文件**（约 49 KB）。引入构建工具没有丢掉"零依赖、双击即玩"这个原型阶段最重要的分发属性。

## 操作

| 键位 | 动作 |
|---|---|
| `W A S D` / 方向键 | 移动 |
| 鼠标移动 | 瞄准 |
| 鼠标左键 | 挥砍（持「蓄力」时改为按住蓄力） |
| `空格` / 鼠标右键 | **朝光标**冲刺，0.17 秒完全无敌 |
| `1` `2` `3` `4` | 选卡 |
| 鼠标左键 | 在地图上点选下一个节点 |
| `ESC` | 暂停（遮蔽式：停表，但战场被完全盖住） |

冲刺方向**只看光标，不看移动键**，而且在按下的那一帧就锁死，途中不能转向。想往哪躲就把光标甩到哪——包括往身后。

挨打会有 **0.18 秒僵直**：动不了、也砍不了，但**过半之后可以用冲刺打断**。被围到第 3 下起僵直减半，避免陷进挣不脱的死循环。

## 规则

**总时间 = 游戏时间 + 受击惩罚 + 秒数消费 − 击杀返还**

一局 = **8 层分支地图**（杀戮尖塔式），开局一次性生成，整张图摊开给你看：

- **战斗房** — 免费从新强化中二选一（战斗消耗的游戏时间就是学费）
- **精英房** — 让已拥有的强化获得专属进化分支
- **秒商店** — 用秒数买强化，永远买得起，因为代价直接记在成绩上
- **捷径门** — 花 9s 跳过一整层，地图上是一条画得出来的跨层斜边
- **时间修复站** — 花 12s 抹掉已累计受击惩罚的 40%

第 1 层固定是战斗房，倒数第二层固定是休整层（商店或修复站），顶层是 Boss。

## 精英进化

精英房会从你已经拥有的强化中展示 **两条进化分支**；两张卡必定来自不同的原强化。展示过的分支会永久离开本局奖励池，即使没有选择；同一强化另一条尚未展示的分支之后仍可能出现。

所有强化都有数值进化；利刃、韧体、连斩还拥有独立的「解除代价」进化。两条分支可以叠加。奖励选择界面会在卡牌上方用大字实时显示**当前总秒数**：选卡免费，但思考仍在计时。

**敌人强度与你的累计时间无关。** 这是纯粹的竞速：所有消费都是同一种单位的直接对赌——花 14 秒买这个强化，能不能在剩下的关卡里帮我省回 14 秒以上？你永远能算，但**算不准**，因为省下多少取决于你接下来打得多好。

## Seed

每一局都由一个 **seed** 完整决定：地图拓扑、房型、墙体布局、敌人生成点、强化与进化分支抽取顺序、Boss 招式。标题页可以手动填，结算页可以一键复制、也可以用同一个 seed 直接再跑一次。

随机分两条流：

| 流 | 何时派生 | 作用 |
|---|---|---|
| `mapRng` | 开局一次 | 整张地图 + 全部房型，**开局就定死** |
| `combatRng` | 每个节点独立，从 `hash(seed, nodeId)` 派生 | 该房间的墙体、敌人生成点、Boss 招式 |

分流是刚需：如果只有一条流，玩家在某个房间里多触发一次随机，后面的地图和商店内容就全变了，同一个 seed 两个人跑出来不是同一局，竞速就没法比。

**`seed + 总时间` 才构成一个可验证、可比较的成绩。**

## 语言

右上角 **`EN` / `中文`** 按钮随时切换界面语言，默认跟随浏览器语言，选择会记在本地存储里。切换是活的——已经拿到的强化、当前显示的商店/结算界面都会立刻换成新语言，不用重开。暂停界面也能切（时钟仍然是停着的）。

英文文案见 [src/i18n/strings.ts](src/i18n/strings.ts)；两份词典的键集合完全一致，少翻译一个键会在编译期报错。

## 连击税

挨打后有 0.4 秒无敌，但**别把它当成免费的穿墙权**。

5 秒内每多挨一次，价码 ×1.3 —— 第一下 2.0s，第二下 2.6s，第三下 3.4s。5 秒不挨打则清零。

## 看价签

场上每一个会收你钱的东西都挂着实时价签，**上面的数字就是你此刻挨这一下会被扣的秒数**，已经算进强化和连击税：

- **红色** — 常态报价
- **橙色加粗** — 连击税生效中，正在加价
- **什么都没有** — 你正处于无敌帧，这一瞬间全场真的不要钱

飞行中的红弹也有价签，靠近时逐渐显现。Boss 会分招式报价：起手三层环 `+3.0s`，起手收缩圆 `+2.5s`，冲锋接触 `+5.0s`。

**子弹不能被打掉**，只能靠走位和冲刺躲。

## 怎么读敌人

红色 = 马上要收你钱。下面标的是无强化、无连击税时的底价。

- **三角形（冲锋兵，+2.0s）** — 画红色锁定射线后高速冲刺。方向在预警开始时就锁死，侧移一步即可
- **方块（射手，+1.5s）** — 红色虚线锁定后打一发红弹
- **六边形（重甲，+4.0s）** — 脚下红圈向外扩，扩满瞬间全圈伤害
- **八边形（Boss）** — 粗红线=三连冲锋 / 收缩圆=环形弹幕 / 三层同心环=三段地震波。半血后进入**回收**二阶段：冲锋会沿最后路线反向折返、两圈 10 发弹幕的缺口相反、震波会从外向内回收。每次回收结束后，金色核心会暴露 0.6 秒并承受 150% 伤害。

## 代码结构

```
src/
  core/      rng（seed 分流）· timeline（游戏时钟）· input · math
  game/      config（全部数值）· pricing（报价单一真相源）· ledger（时间账本）
             world（战斗世界）· player · enemies/（每种怪一个文件）· map · room · run
  i18n/      strings（zh/en 两份词典）· i18n（当前语言状态 + 切换广播）
  render/    renderer · drawWorld · drawMap        —— 只读世界，绝不写它
  scenes/    title · mapScene · combat · reward · shop · result
  ui/        hud · overlay
```

**调平衡只改 [src/game/config.ts](src/game/config.ts)**，不用碰逻辑代码。

### 四条硬性不变式（由测试守着）

1. **报价 === 实扣** —— 屏幕上任何 `+X.Xs` 与账本扣款走同一个 `penaltyFor()` 和同一个 `formatSeconds()`。无敌期间一个字都不画。
2. **所有游戏计时走游戏时钟** —— 不用 `setTimeout`。顿帧、时停、暂停会正确影响每一个排期（Boss 三段震波就靠这个）。
3. **全局禁用 `Math.random()`** —— 所有随机从 seed 派生。一条漏网的就会让整个竞速模式失效，且极难排查，所以用测试当 lint 强制执行。
4. **固定步长** —— 逻辑按 1/120 秒推进，帧率不影响判定与手感。
